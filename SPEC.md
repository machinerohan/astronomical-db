A simple LAMP stack stackoverflow like forum for a crowdsourced astronomical catalogue.
Admins have to approve new registrations.
Everyone can discuss. Threads can be for general discussion or for help in identifying an unknown object.
Only the first message in a thread can ask for identification.
The author of the thread can confirm identifying the object.
These threads can contain proposals to add or change objects.
Experts can approve proposals.
Users with good history of their proposals being approved become experts.
Users can propose disputes for previously proposed proposals and users other than the approver can approve this dispute to revert to last good.
With enough reverts the user loses expert.
Admins can manually verify users which has the same access level as experts.
Only Admins can restrict verified users.
Admins can see why they were verified.
There are subforums for each type of object.
When a proposal is rejected there is a reply message to the proposal with the reason.
When a proposal is approved the message links to a new creation thread for the object.
When an unknown object is identified the message links to the creation thread of that object.
