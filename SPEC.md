A simple StackOverflow-like forum based on simple forum software suitable for a crowdsourced astronomical catalogue.
Forum database links to catalogue database.

1. Admins have to approve new registrations.
2. Everyone can discuss. Threads can be for general discussion or for help in identifying an unknown object.
3. Only the first message in a thread can ask for identification. The author of the thread can confirm identifying the object.
4. These threads can contain proposals to add or change objects.
5. Experts can approve proposals.
Users with good history of their proposals being approved become experts.
6. Users can propose disputes for previously proposed proposals and users other than the approver can approve this dispute to revert to last good.
7. With enough reverts the user loses expert.
8. Admins can manually verify users which has the same access level as experts.
Only Admins can restrict verified users.
Admins can see why they were verified.
9. There are subforums for each type of object.
When a proposal is rejected there is a reply message to the proposal with the reason.
When a proposal is approved it modifies the catalogue database and the reply message links to a creation approval reply for the object.
When an unknown object is identified the reply message links to the creation approval reply of that object in the proposal thread of that object.
10. User profile page with history.
11. Astronomical catalogue with user submitted pictures from proposals.
12. Separte database for astronomical catalogue.
